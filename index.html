About the Club

What is Web Craft?

Web Craft is a hands-on computer club activity focused on equipping students with practical web development skills through structured learning and project-based experiences.

Creative Thinking

Design visually compelling and user-friendly web interfaces that communicate effectively.

Practical Learning

Hands-on sessions covering HTML, CSS, JavaScript, PHP and database integration.

Problem Solving

Tackle real-world web development challenges and build working solutions.

Responsive Design

Learn to build webpages that work seamlessly across all devices and screen sizes.

Web Technologies

Gain proficiency in modern frontend and backend web technologies.

Project-Based Learning

Build, present and evaluate complete mini websites as capstone projects.
